# Evidence and capability scope

## 当前已安装实验版的用户人工截图证据

根据用户在2026-10-10本轮明确确认的人工截图证据：菜单栏图标可见、面板可打开；主 Codex 运行时任务数1、lease存在、Amphetamine活动，界面明确显示 `Agent Wake Manager — managed lease`；自然结束后任务数0、lease空闲、Amphetamine无会话，并有该专用 Trigger ended 通知。

此记录不含虚构截图路径。本轮没有把图像文件导入新仓库，也没有声称独立重拍或重测。证据限该用户的实验版主 Codex 场景；不扩展到其他客户端、GUI控制按钮、首次登录、开发核心或合盖。

|---|---|
