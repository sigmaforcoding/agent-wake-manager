# App icon

`AppIcon.png` is the original 1254 × 1254 PNG with alpha. `AppIcon.icns` packages the standard macOS sizes through 1024 × 1024. The menu-bar status glyph remains a monochrome system symbol; this artwork is the application icon used in Finder and app launchers.

Generated on 2026-10-30 with the built-in OpenAI image generation tool. No third-party reference images or logos were supplied. This provenance record is not a replacement for the project's pending license decision.

Rebuild the icon on macOS (does not install or launch an app):

```sh
zsh scripts/build-icon.sh
```
